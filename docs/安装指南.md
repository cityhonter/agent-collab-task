# 安装指南

> 5 分钟把「Agent 任务中转站」装上你的 AI agent。

---

## 准备工作

在开始之前，确保你有：

1. **一个 Obsidian vault**（或任意本地文件夹）
2. **一个 AI agent**（WorkBuddy / Cursor / Claude Code / ChatGPT 等）
3. **Git**（可选，用于同步中转层）

---

## 步骤 1：准备中转层目录

### 方式 A：放在 Obsidian vault 内（推荐）

如果你已经有 Obsidian vault（或任何本地文件夹）：

```bash
# 在 vault 根目录创建中转层
mkdir -p <vault>/中转层/code/active
mkdir -p <vault>/中转层/code/done
mkdir -p <vault>/中转层/other/active
mkdir -p <vault>/中转层/other/done
mkdir -p <vault>/中转层/templates
mkdir -p <vault>/中转层/archive
```

### 方式 B：独立目录

```bash
# Windows
mkdir "D:\文档\中转层\code\active"
mkdir "D:\文档\中转层\code\done"
mkdir "D:\文档\中转层\other\active"
mkdir "D:\文档\中转层\other\done"
mkdir "D:\文档\中转层\templates"
mkdir "D:\文档\中转层\archive"

# macOS / Linux
mkdir -p ~/Documents/中转层/{code,other}/{active,done}
mkdir -p ~/Documents/中转层/{templates,archive}
```

### 方式 C：使用 Git 同步（推荐，跨机器）

```bash
cd <vault>/中转层
git init
git add .
git remote -m origin https://github.com/你的用户名/zhongzhuan-task-transit.git
git push -u origin main
```

这样你可以在多台机器上同步中转层。

---

## 步骤 2：复制协议文件

从本仓库克隆或下载：

```bash
git clone https://github.com/cityhonter/agent-collab-task.git
cd agent-collab-task
```

然后把模板文件复制到你的中转层：

```bash
# 把模板复制到中转层的 templates 目录
cp templates/*.template <你的中转层>/templates/

# 重命名（去掉 .template 后缀）
cd <你的中转层>/templates
for f in *.template; do mv "$f" "${f%.template}"; done

# 创建初始索引页
cp ../../agent-collab-task/templates/当前关注.md.template <你的中转层>/当前关注.md
```

> 注：如果你按方式 C 用 Git 管理中转层，建议**中转层目录里的 `templates/` 单独建库**，协议仓库和中转层仓库解耦。

---

## 步骤 3：在你的 agent 中安装

根据你用的平台选择：

### WorkBuddy

1. 把整个 `agent-collab-task/` 目录复制到 `~/.workbuddy/skills/`
2. 重命名为 `zhongzhuan-task`（如已存在，备份后替换）
3. 启动 WorkBuddy，输入"配置中转任务路径"或"制定中转任务"
4. agent 会引导你完成配置

### Cursor

1. 把 `SKILL.md` 的内容复制
2. 在项目根目录创建 `.cursorrules`（如不存在）
3. 在文件末尾追加：

```
# === Agent 任务中转站协议 ===
<SKILL.md 内容>
# === 协议结束 ===
```

4. 在 Cursor 设置中配置 TRANSIT_ROOT 路径

### Claude Code

```bash
# 创建 skill 目录
mkdir -p ~/.claude/skills/zhongzhuan-task

# 复制整个仓库
cp -r agent-collab-task/* ~/.claude/skills/zhongzhuan-task/

# 配置（Claude Code 读 .claude/skills/<skill>/SKILL.md）
```

### ChatGPT

1. 打开 ChatGPT → 设置 → 自定义指令（Custom Instructions）
2. 把 SKILL.md 的"工作流"部分粘贴到 "How would you like me to respond?"
3. 在 "What would you like me to know about you?" 写：

```
我使用「Agent 任务中转站」协议管理任务。中转层路径：D:\文档\中转层
我的 agent ID：chatgpt-gpt4
```

### 通用 agent

1. 读 [docs/协议详解.md](协议详解.md)
2. 把 SKILL.md 的核心工作流复制到 agent 的 system prompt
3. 配置 TRANSIT_ROOT 和 AGENT_ID

---

## 步骤 4：首次配置

无论哪个平台，第一次使用时执行：

```
对 agent 说：「配置中转任务路径」
```

agent 会：

1. 检测 `~/.zhongzhuan-task/config.json` 是否存在
2. 不存在就用 `AskUserQuestion` 询问：
   - 中转层根目录路径
   - 你的 agent ID
   - claim 超时小时数（默认 24）
3. 把答案写入配置文件

之后 agent 每次启动会自动加载配置。

---

## 步骤 5：验证

对 agent 说：

> "查看中转任务配置"

应该看到你的配置信息。然后说：

> "看下中转层有什么任务"

应该看到空的索引页（因为还没创建任务）。再创建第一个任务试试：

> "制定中转任务：测试任务，验证安装"

应该看到任务被创建到 `code/active/`（或 `other/active/`，取决于 agent 判断类型）。
